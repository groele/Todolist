# Todolist Chrome Extension (v1.2.1)

一个美观、清新的日程规划与管理 Chrome 扩展。

## 最新更新 (v1.2.1)

- 🔍 **搜索文本高亮显示** - 在任务列表标题、描述及分类中高亮匹配搜索关键字
- 🔊 **Web Audio 优雅提醒音效** - 定时任务提醒时高品质合成音效，带来优雅提醒体验
- 🏷️ **设置页自定义标签管理** - 在设置弹窗中直观预览与一键删除自定义彩色标签
- 📝 **列表行内子任务交互** - 无需打开编辑弹窗，可在任务卡片中直接展示并快速勾选/解勾子任务
- ⌨️ **快捷键交互升级** - 增加 `/` 快捷键聚焦搜索框，`N` 键快速新建任务，`Esc` 全局安全关闭弹窗
- 🔍 **标签与分类一键筛选** - 点击卡片上的任意彩色标签或分类气泡，即可快速搜索该分类/标签下的所有任务
- 🎨 **自定义彩色标签** - 支持动态创建与管理自定义彩色标签
- 📅 **统一日历单元格缩略** - 侧边栏与独立标签页统一支持日历单元格任务标题与优先级色条预览
- 💾 **全量数据备份** - 导出/导入支持完整的任务、设置、自定义标签、模板、搜索历史及计时记录

## 功能特性

- ✅ **任务管理** - 添加、编辑、删除、复制、完成任务
- 📅 **日历视图** - 月度日历查看任务分布与缩略
- 🎯 **优先级标记** - 高/中/低三级优先级
- 🏷️ **分类与标签** - 支持自定义分类与动态彩色标签
- 🔍 **搜索筛选** - 快速查找任务与历史搜索建议
- 📊 **智能分组** - 按状态自动分组（逾期、今天、即将到来、已完成）
- 💾 **全量数据备份** - 支持完整 JSON 导入导出、CSV、Markdown、TXT 导出
- 🔄 **撤销删除** - 删除后可防覆盖撤销
- 📱 **侧边栏与全屏模式** - 浏览网页时保持侧边栏打开，也可在大屏查看看板分栏

## 安装步骤

1. 下载或克隆本项目到本地
2. 打开 Chrome 浏览器，进入扩展管理页面：`chrome://extensions/`
3. 开启右上角的「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择项目文件夹 `D:\Dev Studio\Todolist`
6. 扩展图标将出现在浏览器工具栏

## 使用方法

### 打开扩展
- 点击浏览器工具栏中的扩展图标
- 侧边栏将自动打开

### 添加任务
1. 点击右上角的 `+` 按钮
2. 填写任务信息：
   - 标题（必填）
   - 描述（可选）
   - 截止日期（可选）
   - 优先级（默认中等）
   - 分类（可选）
3. 点击「保存」

### 管理任务
- **完成任务**：点击任务左侧的圆形复选框
- **编辑任务**：点击任务卡片
- **删除任务**：悬停任务卡片，点击删除按钮（可撤销）

### 视图切换
- **列表视图**：默认视图，按状态分组显示
- **日历视图**：点击右上角日历图标切换

### 筛选和搜索
- **搜索**：在搜索框输入关键词
- **优先级筛选**：使用下拉菜单选择
- **状态筛选**：使用底部标签页切换（全部/今天/即将到来/已完成）
